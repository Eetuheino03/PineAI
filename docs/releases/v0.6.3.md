# PineAI v0.6.3 — Hardening, Performance Validation & Audit Fixes

PineAI `0.6.3` is a stability, hardening, and performance release that addresses all confirmed P0 and most P1 findings from the comprehensive code audit.

## Summary of Changes

### 1. Backend Core & Store Fixes (P0)
- **`CustomerAuditStore.update_finding()` Signature**: Fixed to accept `note: str = ""` parameter and forward to the base store's append-only audit event.
- **Lazy AI Validation Import**: Added lazy import `from .ai_analysis import validate_ai_analysis` inside `_validated_report_ai()` in `assurance_service.py` to prevent `NameError` during AI report generation.
- **Strict Public Report Action Contract**: Updated `generate_report_action` in `module.py` to validate public requests, requiring explicit `scope` dictionary and 64-character SHA-256 `scope_digest` string. Rejects invalid or missing scopes with `invalid_report_scope`.

### 2. Byte-Budgeted LRU Cache (P1)
- Replaced count-only eviction in `AssessmentStore` with `collections.OrderedDict`-based LRU cache.
- Configured explicit accounting bounds: `CACHE_MAX_ITEMS = 64`, `CACHE_MAX_SERIALIZED_BYTES = 4 MiB`, `CACHE_MAX_ITEM_BYTES = 256 KiB`.
- Added `threading.RLock()` around cache operations and stat pre/post verification for read-race protection.

### 3. Benchmark Harness (`scripts/benchmark_backend.py`) (P1)
- Implemented `--mode local-adapter` for in-process service initialization microbenchmark (CI & workstations).
- Implemented `--mode mark-vii-socket` stub for physical Mark VII benchmarking. **Note:** The native socket protocol, path, and framing have not been validated against a physical Mark VII device. This mode requires field validation before reliance.
- Outputs machine-readable JSON (`--json`) recording service initialization latency, action percentiles (p50/p95/max), peak RSS (VmHWM on Linux), and cache hit/miss/eviction metrics.

### 4. Frontend Initialization & UI Fixes (P1)
- **Shared `initializationPromise`**: Concurrent `initialize()` callers share a single promise. Second caller receives the same promise instead of silently returning.
- **Explicit Resource Load States**: Added `ResourceLoadState` (`'not_loaded' | 'loading' | 'loaded' | 'failed'`) to `measurementProfilesState` and `reconState`. Loaders no longer rely on `settle()` — errors now correctly transition state to `'failed'` and are recorded in `panelErrors`.
- **Capability Error Propagation**: `refreshCapabilities()` now logs individual capability request failures to `panelErrors` instead of silently catching to null.
- **Guided Draft Preservation**: Switched from `*ngIf` to `[hidden]` so draft fields survive mode switches between Guided and Expert.
- **Comparability UI Alignment**: Updated `assets-changes.component.html` to read from `quality_factors` sub-object with Angular 9 compatible fallback expressions. Fixed taxonomy CSS selectors.
- **Search Debounce Wiring**: Connected `onSearchChange()` (200 ms debounce) to the search input `(ngModelChange)` binding. Clear button still calls `onFilterChange()` directly.
- **Findings Split View**: Re-bound `selectedFinding` on filter updates. Added `@media (max-width: 720px)` responsive CSS.

### 5. Versioning, Documentation & CI Hardening
- Synchronized release version to `0.6.3` across `module.json`, backend `__version__`, `baseline-drift-v1.schema.json`, `customer-audit-v1.schema.json`, `README.md`, and `docs/customer-audit.md`.
- Created `tests/test_version_consistency.py` to enforce version alignment.
- Added `ruff` static analysis, `npm run lint`, and local adapter benchmark validation steps to `.github/workflows/build.yml`.

## Known Limitations

- **Mark VII Socket Benchmark**: The `mark-vii-socket` mode exists but has not been validated against a physical Mark VII. The socket path, framing protocol, and response parsing are based on assumptions that need field verification.
- **Cache Byte-Budget Testing**: Tests cover item-count eviction, oversized-item bypass (256 KiB limit), LRU promotion, deep-copy behavior, invalidation, malformed JSON, and aggregate 4 MiB byte-budget eviction. Concurrent read-race tests remain pending.
- **Physical Mark VII Verification**: The release package builds and passes automated tests. Physical device testing remains pending.
