# PineAI v0.6.2 — Customer Audit Foundation

PineAI now provides portable, offline wireless change auditing for saved WiFi
Pineapple Recon observations.

## Included

- two-to-five scan strict-80 consensus baselines;
- versioned measurement profiles and capability status;
- immutable inventory-plus-policy AssuranceProfiles;
- separate observed changes, policy deviations, and security findings;
- immutable point-in-time occurrences and before/after evidence;
- comparison, current-state, and history JSON/HTML reports;
- Guided workflow and Expert mode;
- root/SSH backup create, verify, and safe staging restore;
- identity continuity and recoverable multi-file transaction hardening.

AI remains optional and non-authoritative. PineAI works completely offline and
does not control radios.

## Compatibility

v0.6.0/v0.6.1 assessment data remains readable. Old single-scan baselines are
shown as `single_scan`. Legacy comparisons without point-in-time occurrence
facts are reported as limited; PineAI does not reconstruct facts it cannot
prove. Legacy findings remain read-only history.

After v0.6.2 writes new state, downgrade requires restoring both the earlier
module and a matching full `/root/.PineAI` backup.

## Validation boundary

Automated Python, Angular, schema, package, secret, and checksum validation is
required before publication. The GitHub release remains a pre-release until
the exact published asset later passes a physical WiFi Pineapple Mark VII smoke
test. This implementation does not touch a physical device.
