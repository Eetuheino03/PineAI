# PineAI v0.6.0 — Baseline & Drift

PineAI is now an offline-first wireless assurance module for the WiFi
Pineapple Mark VII.

## Highlights

- immutable, explicitly activated Recon baselines;
- deterministic scan comparability and AP/SSID drift;
- eight evidence-backed finding rules;
- stable finding lifecycle with acknowledgment, false-positive state,
  automatic resolution, and deterministic recurrence reopening;
- standalone JSON and script-free HTML reports;
- nine-view responsive Angular workflow;
- optional, privacy-filtered AI explanations that cannot change authoritative
  results;
- standard-library-only Python backend and private on-device storage.

This release removes the old public Target Profiler, Attack-Path Advisor,
Engagement, and Adaptive Recon interfaces. Existing legacy engagement files
remain untouched and unused.

## Verification

- Windows Python suite
- WSL Python suite including POSIX permissions
- Angular ChromeHeadless suite
- Angular 9 production build
- Python 3.8 and Node 16 GitHub Actions
- Hak5 archive structure, ownership, modes, SHA-256, and secret scan

Physical Mark VII behavior is documented separately in the release handoff if
hardware smoke testing is still pending.
